# License gate

Run this before every install or download. A failed check stops that item. Say which rule failed and pick another catalog record. Do not invent a lookalike.

1. The catalog record has `tier: free`, or the request meets a conditional rule on this page exactly.
2. Commercial use inside an end product is free. Refuse `@magicui-pro`, React Bits Pro, Aceternity blocks and templates, Hover items that are not marked Free, and Refero MCP.
3. The catalog stores a command and a URL. It does not store component source. This skill does not store Lottie or Icons8 files.
4. React Bits and Aceternity may be used inside the product. Do not republish that source as a component library, template, or marketplace listing.
5. A Lottie file is downloaded only after that animation's own page states the Lottie Simple License. One file per request. Premium animations stop the task. Bulk downloads stop the task.
6. A Hover.dev component is copied only when the user points at a page marked Free.
7. Icons come from the project's `iconLibrary` in `components.json`. The default is Lucide. Icons8 is unused.
8. A `DESIGN.md` from awesome-design-md guides tokens and tone. Do not copy logos, wordmarks, or brand asset files.

Registry URLs that 401, 402, or 403, or whose path contains a `pro` segment, are refused.
