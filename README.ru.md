# Visual Craft GTR

[English](README.md)

![Visual Craft](assets/cover.png)

Внешний MCP-сервер и пак правил для Cursor. В проекте на React и Tailwind Cursor ставит настоящие бесплатные компоненты из каталога. Сервер сам файлы в этот проект не пишет.

## Что можно попросить

Каждая строка — отдельная просьба. Слова решают, какая часть страницы меняется. Компонент ставит Cursor. Сервер только называет его.

- **Целый лендинг.** Попросите лендинг. Visual Craft собирает его из бесплатного каталога: навигация, первый экран, цены, которые вы назвали, вопросы и ответы, подвал из ваших ссылок. Одна тема и один файл оформления.
- **Анимированный лендинг.** Назовите движение. Фон, эффект заголовка и вторая анимация делаются. Более тихая страница — только совет.
- **Кнопка.** Попросите переделать только эту кнопку. Меняется она. Остальная страница остаётся.
- **Анимация кнопки.** Попросите только анимацию на этой кнопке. Нажатие, ошибка и успех остаются на ней. Стиль страницы не трогается.
- **Свой стиль.** Попросите только стиль. Один файл оформления и одна тема. Секции остаются на своих местах.
- **Оставить текущий стиль.** Новый экран берёт тему, которая уже есть в проекте.
- **Экран входа.** Готовый блок входа из каталога: нажатие, ошибка и успех. Форма не рисуется по памяти.
- **Фон.** Лучи, частицы или сияние, если вы назвали такой фон.
- **Движение заголовка.** Маска, размытие или появление текста, если вы назвали заголовок.
- **Иконки.** Lucide в пустых местах новых элементов или когда вы просите только иконки.
- **QR-код.** Собирается в проекте, когда вы его просите. Отсутствие записи в каталоге — не отказ.
- **Одна иллюстрация.** Один файл Lottie, на странице которого указана Simple License, вместе с файлом кредитов.
- **Пустой экран.** Пустое состояние из каталога, которое зовёт к следующему действию.
- **Момент успеха.** Галочка, когда позиция впервые попадает в корзину, или конфетти, когда запись прошла.
- **Магазин, каталог или одностраничный инструмент.** То же визуальное правило, что у лендинга. Названный эффект делается. Тип продукта его не отменяет.
- **Без анимации.** Скажите об этом, и движение остаётся закрытым.

Платный реестр, чужой логотип, Icons8 и пачка файлов Lottie остаются отказом.

## Фразы

- Целая страница: `Используй Visual Craft. Сделай лендинг.`
- Только кнопка: `Используй Visual Craft. Только эту кнопку.`
- Только анимация: `Используй Visual Craft. Только анимацию на этой кнопке.`
- Только стиль: `Используй Visual Craft. Только стиль.`

## Как это работает

Запущенный сервер отвечает, что ставить. Пак отвечает, куда это положить. Просьба человека важнее вкуса: названные фон, вторая анимация или QR-код делаются. Отказ остаётся на лицензии, чужом логотипе и платном реестре.

`examples/burger-life` — пробный лендинг в этом репозитории. `examples/gate-pass` — одностраничный инструмент с фоном, анимацией кнопки и QR-кодом. Оба файла не инструкция по установке.

## Запуск

Из папки `mcp/visual-craft`: `npm start`. Остановка: `npm run stop`. Адрес: `http://127.0.0.1:3847/mcp`. На Windows `start-visual-craft-mcp.bat` и `stop-visual-craft-mcp.bat` вызывают те же команды.

Добавьте это внутрь `mcpServers` в `%USERPROFILE%\.cursor\mcp.json` (на macOS и Linux это `~/.cursor/mcp.json`):

```json
"visual-craft": {
  "url": "http://127.0.0.1:3847/mcp"
}
```

В Cursor перечитайте список MCP. Проект уже должен быть на React и Tailwind.

## Источники

Берётся только бесплатная версия каждого сайта.

- [shadcn/ui](https://ui.shadcn.com)
- [Magic UI](https://magicui.design), бесплатные компоненты
- [Aceternity UI](https://ui.aceternity.com), бесплатные компоненты
- [React Bits](https://reactbits.dev), бесплатные записи TypeScript и Tailwind
- [Luxe](https://www.luxeui.com)
- [tweakcn](https://tweakcn.com), токены тем
- [Lucide](https://lucide.dev)
- [LottieFiles](https://lottiefiles.com), один файл, на странице которого указана Lottie Simple License
- [Hover.dev](https://www.hover.dev), только страница с пометкой Free
- [awesome-design-md](https://github.com/voltagent/awesome-design-md), только настроение, без логотипов

Pro-реестры, Refero MCP и Icons8 в эту сборку не входят.

Скиллы со skills.sh, которые едут вместе с паком: `landing-copy`, `frontend-design`, `shadcn`, `web-design-guidelines`, `review-animations`.
